# Data Analytics Projects

This repository contains practical data analytics and business intelligence projects focused on exploring data, building structured models, and delivering clear analytical insights.

The work demonstrates applied use of Power BI, SQL, and Python in solving real-world analytical tasks.

## Power BI Projects

### Disney Industry Analysis
An interactive Power BI project analysing Disney movie performance over time.

**Key topics:**
- Revenue trends and inflation-adjusted analysis
- Genre and MPAA rating impact
- Character and voice actor contribution
- STAR schema data model
- Business-oriented insights and storytelling
